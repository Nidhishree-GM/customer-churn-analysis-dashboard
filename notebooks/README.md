# Customer Churn Analysis

## Project Overview
This project analyzes customer churn data using Python, SQL, and Power BI.

The goal of this project is to identify churn patterns, analyze customer behavior, and generate business insights through dashboards and SQL analysis.

---

## Tools & Technologies Used
- Python
- Pandas
- Matplotlib
- Seaborn
- MySQL
- SQLAlchemy
- Power BI
- VS Code

## Key Business Insights
- Overall churn rate is around 34%
- Finance industry has the highest churn
- Education industry has the lowest churn
- Customers with low logins and low NPS score are more likely to churn
